Cài đặt chung & Khởi động

Trình duyệt mặc định

Đặt Papyrus làm trình duyệt chính để mở mọi liên kết web trên Windows.

Khôi phục tab lưu địa chỉ URL vào tệp cài đặt nội bộ, không phục hồi trạng thái biểu mẫu chưa gửi.

Giao diện & Hiển thị

Icon đại diện chính thức của Papyrus là huy hiệu chữ PRS màu nâu đậm trên nền giấy thủ công.

Quyền riêng tư & Bảo mật

Cookie, cache và dữ liệu duyệt web được lưu an toàn trong hồ sơ riêng biệt của Papyrus. Cài đặt và danh sách ghim được quản lý độc lập.

Đóng mọi tab đang mở và xóa sạch cookie, cache bộ nhớ tạm, lịch sử duyệt web WebView2. Giữ nguyên ghim và cài đặt cá nhân.

Tiện ích mở rộng (Extensions / Add-ons)

Papyrus hỗ trợ đầy đủ cài đặt và kích hoạt tiện ích mở rộng chuẩn Chromium thông qua nhân WebView2.

Bạn có thể truy cập Chrome Web Store hoặc Edge Add-ons để tìm kiếm và cài đặt tiện ích yêu thích (uBlock Origin, Dark Reader, Translate, v.v.).

Bộ lọc tên miền & Chặn quảng cáo

Số lượng tên miền chặn tích hợp sẵn: mục. Nhập mỗi dòng một tên miền; quy tắc sẽ tự động áp dụng cho cả tên miền con.

Sau khi lưu danh sách bộ lọc mới, hãy tải lại trang web để áp dụng thay đổi.

Tệp tải xuống (Downloads)

Papyrus bảo vệ bạn bằng cách kiểm tra tên tệp hợp lệ và không tự động thực thi tệp sau khi tải về.

Lịch sử tệp đã tải trong phiên:

    Phím tắt nhanh & Công cụ lập trình viên

    Papyrus hỗ trợ đầy đủ các tổ hợp phím tắt chuẩn của trình duyệt:

    • Ctrl + H: Mở Lịch sử duyệt web (History)
    • Ctrl + J: Mở Tệp tải xuống (Downloads)
    • Ctrl + Shift + T: Khôi phục tab vừa đóng gần nhất
    • Ctrl + + / Ctrl + - / Ctrl + 0: Phóng to / Thu nhỏ / Đặt lại 100%
    • Ctrl + P: In trang web (Print)
    • Ctrl + Tab / Ctrl + Shift + Tab: Chuyển tab tiếp theo / tab trước đó
    • Ctrl + 1..đến..8: Chuyển trực tiếp tab 1 đến 8 (Ctrl+9: Tab cuối)
    • F12 hoặc Ctrl + Shift + I: Mở Công cụ phát triển DevTools
    • Ctrl + T: Mở Tab mới | Ctrl + W: Đóng tab | Ctrl + L: Chọn thanh URL
